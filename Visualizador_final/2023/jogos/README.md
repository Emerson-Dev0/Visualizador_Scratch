# Jogos offline de 2023

Coloque aqui os HTMLs exportados dos projetos de 2023.

Depois de adicionar um arquivo, atualize o campo `arquivo` em `../projetosOffline.js`.

Exemplo:

```js
arquivo: "jogos/GaFer Maze.html"
```

Rode `npm run validate` na raiz do projeto para conferir se o caminho esta correto.
