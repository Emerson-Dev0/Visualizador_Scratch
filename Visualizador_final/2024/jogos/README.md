# Jogos offline de 2024

Coloque aqui os HTMLs exportados dos projetos de 2024.

Depois de adicionar um arquivo, atualize o campo `arquivo` em `../projetos24.js`.

Exemplo:

```js
arquivo: "jogos/Labirinto Estrelar.html"
```

Rode `npm run validate` na raiz do projeto para conferir se o caminho esta correto.
